# Allure Sample Results and HTML Reports

This folder contains static Allure-style report examples for GitHub review.

These files are not a replacement for the live Allure report generated by Maven. They are included so reviewers can inspect example pass/fail output directly in the repository without running the test suite.

## Included files

```text
13_Reports/allure-sample-results/
|-- README.md
|-- index.html                         # Main static Allure-style dashboard
|-- passed-report.html                 # Passed test case examples
|-- failed-report.html                 # Failed test / defect examples
|-- surefire-report.html               # Human-readable Surefire summary
|-- allure-report-screenshot-6-3-2026.svg
|-- environment.properties             # Example environment metadata
`-- sample-allure-results.json         # Simplified Allure-style data sample
```

## Live Allure generation

Run this from the repository root:

```bash
mvn clean test -Pallure-ui -Dbrowser=chrome -Dheadless=true -Dallure.results.directory=target/allure-results
mvn allure:report
```

Open:

```text
target/site/allure-report/index.html
```

## GitHub Actions UI

The preferred cloud UI is GitHub Actions plus GitHub Pages:

1. Open the repository in GitHub.
2. Go to **Actions**.
3. Run **Selenium CI/CD Pipeline with Allure Reports**.
4. Use profile `allure-ui` for a stable run.
5. Download artifacts or open the GitHub Pages Allure report.
