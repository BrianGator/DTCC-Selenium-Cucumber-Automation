# Intentional Failure Examples

Purpose: Contains intentionally failing tests that are isolated in a separate suite for pass/fail report demonstration.

Executable implementation: `src/test/java/com/dtcc/automation/reports/IntentionalFailureExampleTest.java`

Run command example:

```bash
mvn test -Dtest=IntentionalFailureExampleTest test
```

Reviewer note: this folder is a navigation-friendly copy/reference area. The executable Maven source lives under `src/test/java` so the project follows standard Java automation structure.
