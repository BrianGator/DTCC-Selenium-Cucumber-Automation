# Accessibility Tests

Purpose: Checks basic accessibility expectations such as field labels and ARIA support.

Executable implementation: `src/test/java/com/dtcc/automation/accessibility/AccessibilitySmokeTest.java`

Run command example:

```bash
mvn test -Dtest=AccessibilitySmokeTest test
```

Reviewer note: this folder is a navigation-friendly copy/reference area. The executable Maven source lives under `src/test/java` so the project follows standard Java automation structure.
