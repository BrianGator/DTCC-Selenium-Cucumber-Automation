# Performance Tests

Purpose: Runs a smoke-level response-time check against public pages.

Executable implementation: `src/test/java/com/dtcc/automation/performance/PageLoadPerformanceTest.java`

Run command example:

```bash
mvn test -Dtest=PageLoadPerformanceTest test
```

Reviewer note: this folder is a navigation-friendly copy/reference area. The executable Maven source lives under `src/test/java` so the project follows standard Java automation structure.
