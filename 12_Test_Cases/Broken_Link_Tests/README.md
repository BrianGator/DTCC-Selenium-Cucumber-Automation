# Broken Link Tests

Purpose: Checks representative navigation links for HTTP 4xx/5xx failures.

Executable implementation: `src/test/java/com/dtcc/automation/links/BrokenLinkValidationTest.java`

Run command example:

```bash
mvn test -Dtest=BrokenLinkValidationTest test
```
