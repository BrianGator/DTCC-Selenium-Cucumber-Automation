# Data Driven Tests

Purpose: Uses TestNG DataProvider to validate multiple login input combinations.

Executable implementation: `src/test/java/com/dtcc/automation/datadriven/DataDrivenLoginValidationTest.java`

Run command example:

```bash
mvn test -Dtest=DataDrivenLoginValidationTest test
```

Reviewer note: this folder is a navigation-friendly copy/reference area. The executable Maven source lives under `src/test/java` so the project follows standard Java automation structure.
