Surefire/TestNG Runner Evidence

How To Read This Area

Surefire is secondary raw CI evidence. Use Allure as the primary UI report; use this page for Maven/TestNG XML, skipped intentional demos, and runner diagnostics.

Stable failures/errors should be 0. Intentional demos are skipped unless enabled.
